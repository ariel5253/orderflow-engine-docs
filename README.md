# orderflow-engine-docs

[Español](README.es.md)

Documentation of **Orderflow Engine**: the pricing engine and idempotent order confirmation of a multi-country B2B beverage marketplace. The original assignment is in [`assignment/`](assignment/). The deliverable code, its README and the ADR live in the `orderflow-engine-api` repository. The delivery set (user manual, technical manual, architecture report, solution walkthrough and presentation source) lives in [`delivery/`](delivery/), and the public page in the `orderflow-engine-page` folder. Other repositories are cited by name, without links, so that each repository stands alone when cloned.

> **Opening a new session? Start with [`handoff/HANDOFF.md`](handoff/HANDOFF.md).** It holds the verified state, the commands to resume, the open decisions and the traps already found.

```
orderflow-engine-docs/
├─ README.md · README.es.md   this file: the map and glossary of the whole workspace
├─ LICENSE                    MIT
├─ handoff/                   the only place where the verified state lives, with the progress chart
├─ spec/                      the living specification (English)
├─ assignment/                the original assignment, untouchable
├─ diagrams/                  generated SVG figures, numbered by first appearance
├─ governance/                golden rule, branches, pull requests, commits, documentation rules
├─ delivery/                  the delivery set in English and Spanish: manuals, report, walkthrough, presentation source
│  ├─ screenshots/            the web client screens, one folder per language (en, es)
│  └─ figures/                the diagrams as PNG images, one per SVG
└─ deliverables/             the ADR in Word and PDF (generated) and manifest.json with the source of each
   └─ delivery/               the delivery set in Word and PDF, and the presentation deck in PowerPoint (generated)
```

**The ordering rule of this folder, in one line: the root holds only the READMEs and the license.** Everything else lives in a folder, and the glossary below says who edits each one.

## Checking the documentation

```bash
node orderflow-engine-tools/docs-check/check-docs.mjs
```

Run it from the workspace root. The tools live in the `orderflow-engine-tools` repository; this folder only keeps their results. It fails on any of these:
- unindexed or misplaced Markdown files
- missing language pairs
- broken relative links, including figures
- invalid front matter
- a missing required heading, such as the four README topics the assignment requires
- an ADR longer than one page
- mismatched i18n keys
